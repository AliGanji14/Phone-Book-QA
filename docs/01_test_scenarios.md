# سناریوهای تست


## ۱. سناریوهای سمت کلاینت (Client)

| شناسه | عنوان سناریو | شرح |
|---|---|---|
| CS-01 | ارسال فایل دستورات معتبر | کاربر فایل JSON معتبر (مانند `samples/commands.json`) را ارسال می‌کند و پاسخ سرور نمایش داده می‌شود |
| CS-02 | فایل ناموجود | مسیر فایل JSON وجود ندارد؛ کلاینت باید خطای مناسب چاپ کند و کرش نکند |
| CS-03 | فایل JSON نامعتبر | محتوای فایل JSON قابل parse نیست؛ کلاینت باید خطای مناسب چاپ کند |
| CS-04 | سرور در دسترس نیست | کلاینت با پورت/IP اشتباه اجرا می‌شود؛ رفتار کلاینت (timeout یا انتظار بی‌نهایت) بررسی می‌شود |
| CS-05 | اعتبارسنجی ورودی ثبت‌نام | قالب ایمیل واردشده در sign_up بررسی می‌شود (اجرای دستی) |
| CS-06 | ذخیره امن رمز عبور | بررسی دستی دیتابیس: رمز هش‌شده و salt یکتا ذخیره شده باشد (اجرای دستی) |

## ۲. سناریوهای سمت سرور (Server)

| شناسه | عنوان سناریو | شرح |
|---|---|---|
| SS-01 | ثبت‌نام (sign_up) | ثبت‌نام موفق، ساختار پاسخ استاندارد، ثبت‌نام با نام کاربری تکراری |
| SS-02 | ورود (sign_in) | ورود با رمز درست، رمز نادرست، کاربر ناموجود |
| SS-03 | خروج (logout) | خروج کاربر واردشده، خروج کاربری که وارد نشده |
| SS-04 | افزودن مخاطب (add_phone_user) | با توضیحات، بدون توضیحات (اختیاری بودن)، نام کاربری تکراری، نبود پارامتر الزامی |
| SS-05 | الزام احراز هویت | دستورات دفترچه تلفن باید فقط پس از sign_in مجاز باشند |
| SS-06 | افزودن شماره (add_phone_number) | افزودن شماره دوم به مخاطب موجود، شماره تکراری |
| SS-07 | ویرایش مخاطب (edit_phone_user) | تغییر فقط نام، تغییر فقط شماره، ارسال ناقص پارامترها، ویرایش مخاطب ناموجود |
| SS-08 | حذف مخاطب (remove_phone_user) | حذف مخاطب موجود، حذف مخاطب ناموجود |
| SS-09 | لیست کامل (get_all_phone_users) | دریافت لیست تمام مخاطبین با همه شماره‌ها |
| SS-10 | جستجو با نام (get_phone_user_by_name) | مخاطب موجود (شامل توضیحات)، مخاطب ناموجود |
| SS-11 | جستجو با شماره (get_phone_user_by_number) | شماره موجود، شماره ناموجود |
| SS-12 | دستورات نامعتبر | command_name ناشناخته، payload خراب (شیء به‌جای لیست)، لیست خالی |
| SS-13 | پایداری سرور | سرور باید پس از هر خطا به کار عادی ادامه دهد و پاسخ خطا را در قالب استاندارد برگرداند |

## ۳. سناریوهای غیرعملکردی (مورد اختیاری فایل ارزیابی)

| شناسه | عنوان سناریو | شرح |
|---|---|---|
| NF-01 | زمان پاسخ‌دهی | پاسخ به یک کوئری ساده باید زیر ۲ ثانیه باشد |
| NF-02 | بارگذاری حجمی | افزودن ۳۰ مخاطب در یک درخواست باید زیر ۳ ثانیه انجام شود |
